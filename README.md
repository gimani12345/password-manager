# 🔐 비밀번호 관리자 (Password Manager)

C# Windows Forms 기말 프로젝트

---

## 📌 프로젝트 소개

AES-256 암호화 기반의 **로컬 비밀번호 관리 프로그램**입니다.

사이트별 아이디와 비밀번호를 암호화하여 안전하게 저장하고, 마스터 비밀번호 하나로 모든 계정 정보를 관리할 수 있습니다. 비밀번호 데이터는 로컬 JSON 파일에 AES-256으로 암호화되어 저장되므로, 파일이 유출되더라도 내용을 확인할 수 없습니다.

---

## ✨ 주요 기능

### 🔑 마스터 비밀번호 로그인
- 프로그램 실행 시 마스터 비밀번호로 인증
- 비밀번호는 SHA-256으로 해싱하여 저장 (평문 저장 없음)
- 초기 비밀번호: `1234a!`
- 로그인 성공 시에만 메인 화면 진입 가능

### 🛡️ 로그인 잠금 (Brute-Force 방지)
- 비밀번호 5회 오입력 → **30초** 잠금
- 비밀번호 10회 오입력 → **60초** 잠금
- 비밀번호 15회 이상 오입력 → **5분** 잠금
- 잠금 중 로그인 시도 시 남은 시간 안내

### 🔒 비밀번호 저장 및 암호화
- 사이트명 / 아이디 / 비밀번호를 입력하여 저장
- 저장 데이터는 **AES-256**으로 암호화 후 JSON 파일에 기록
- 파일을 직접 열어도 암호화된 내용만 확인 가능

### 🎲 랜덤 비밀번호 생성
- 12~16자리의 보안 비밀번호 자동 생성
- 대문자 / 소문자 / 숫자 / 특수문자 조합
- 암호학적으로 안전한 `RNGCryptoServiceProvider` 사용

### 💪 비밀번호 강도 표시
비밀번호 입력 시 아래 기준으로 실시간 강도 표시:

| 점수 | 강도 | 색상 |
|------|------|------|
| 0 ~ 2점 | 약함 | 🔴 빨강 |
| 3점 | 보통 | 🟠 주황 |
| 4 ~ 5점 | 강함 | 🟢 초록 |

> 판단 기준: 8자 이상 / 대문자 포함 / 소문자 포함 / 숫자 포함 / 특수문자 포함

### 📋 비밀번호 복사
- 복사 버튼 클릭 시 클립보드에 즉시 복사
- 화면에는 `******` 으로 표시되어 비밀번호 노출 방지

### 🔍 사이트 검색
- 상단 검색창에 사이트명 입력 시 실시간 필터링
- 대소문자 구분 없이 검색 가능

### 🌐 사이트 바로가기
- 사이트명 클릭 시 기본 브라우저로 해당 사이트 열기
- `http://` 또는 `https://` 없이 입력해도 자동으로 추가

### ❓ 보안 질문으로 비밀번호 찾기
- 마스터 비밀번호 분실 시 보안 질문으로 재설정 가능
- 보안 질문 5종 중 선택하여 설정
- 질문과 답변 모두 AES-256으로 암호화 저장

### 🔧 마스터 비밀번호 변경
- 현재 비밀번호 확인 후 새 비밀번호로 변경
- 새 비밀번호 강도 실시간 표시

## 🚀 실행 방법

1. Visual Studio 2022에서 `Project.sln` 열기
2. 상단 메뉴 → 빌드 → 솔루션 빌드 (또는 `Ctrl + Shift + B`)
3. `F5`로 실행
4. 초기 마스터 비밀번호 `1234a!` 입력 후 로그인

> ⚠️ Windows 환경에서만 실행 가능합니다.

## 📁 프로젝트 구조

```
password-manager/
├── Project.sln
└── Project/
    ├── Program.cs                  # 진입점 — 로그인 후 메인폼 실행
    ├── MainForm.cs                 # 메인 화면 — 비밀번호 목록 / 검색 / 삭제
    ├── AddPwd.cs                   # 비밀번호 추가 / AES 암호화 클래스 / 데이터 저장
    ├── LoginForm.cs                # 마스터 비밀번호 로그인 / 잠금 처리
    ├── ChangeMainPwd.cs            # 마스터 비밀번호 변경
    ├── FindPasswordForm.cs         # 보안 질문으로 비밀번호 재설정
    ├── SetSecurityQuestionForm.cs  # 보안 질문 설정
    └── PasswordEntry.cs            # 비밀번호 데이터 모델 (SiteName / IdName / Password)
```

## 🔐 보안 구조

| 데이터 | 저장 방식 | 저장 파일 |
|--------|-----------|-----------|
| 사이트별 비밀번호 목록 | AES-256 암호화 | `password.json` |
| 마스터 비밀번호 | SHA-256 해싱 | `programPassword.json` |
| 보안 질문 / 답변 | AES-256 암호화 | `securityQuestion.json` |

### 암호화 흐름

```
[입력 데이터]
     ↓
JSON 직렬화
     ↓
AES-256 암호화 (Key: 32바이트, IV: 16바이트)
     ↓
Base64 인코딩
     ↓
[파일 저장]
```

### 마스터 비밀번호 흐름

```
[입력 비밀번호]
     ↓
SHA-256 해싱
     ↓
저장된 해시값과 비교
     ↓
[인증 성공 / 실패]
```
