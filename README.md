# 🔐 비밀번호 관리자 (Password Manager)

C# Windows Forms 기말 프로젝트

---

## 📌 프로젝트 소개

AES-256 암호화 기반의 로컬 비밀번호 관리 프로그램입니다.
사이트별 아이디와 비밀번호를 안전하게 저장하고 관리할 수 있습니다.

---

## ✨ 주요 기능

- 🔑 **마스터 비밀번호 로그인** — SHA-256 해싱으로 안전하게 저장
- 🔒 **비밀번호 저장** — AES-256 암호화된 JSON 파일로 관리
- ➕ **비밀번호 추가** — 사이트명 / 아이디 / 비밀번호 등록
- 🎲 **랜덤 비밀번호 생성** — 12~16자리 보안 비밀번호 자동 생성
- 💪 **비밀번호 강도 표시** — 입력 시 실시간으로 약함 / 보통 / 강함 표시
- 📋 **비밀번호 복사** — 클립보드에 한 번에 복사
- 🔍 **사이트 검색** — 사이트명으로 빠르게 검색
- 🌐 **사이트 바로가기** — 사이트명 클릭 시 브라우저에서 열기
- 🛡️ **로그인 잠금** — 5회 실패 시 30초, 10회 실패 시 60초, 15회 이상 시 5분 잠금
- ❓ **보안 질문** — 마스터 비밀번호 분실 시 보안 질문으로 재설정

## 🚀 실행 방법

1. Visual Studio 2022에서 `Project.sln` 열기
2. 빌드 후 실행 (`F5`)
3. 초기 마스터 비밀번호: `1234a!`

---

## 📁 프로젝트 구조

```
Project/
├── Program.cs                  # 진입점 (로그인 후 메인폼 실행)
├── MainForm.cs                 # 메인 화면 (비밀번호 목록, 검색)
├── AddPwd.cs                   # 비밀번호 추가 / AES 암호화 / 데이터 저장
├── LoginForm.cs                # 마스터 비밀번호 로그인
├── ChangeMainPwd.cs            # 마스터 비밀번호 변경
├── FindPasswordForm.cs         # 보안 질문으로 비밀번호 찾기
├── SetSecurityQuestionForm.cs  # 보안 질문 설정
└── PasswordEntry.cs            # 비밀번호 데이터 모델
```

## 🔐 보안 구조

| 데이터 | 저장 방식 |
|--------|-----------|

| 마스터 비밀번호 | SHA-256 해싱 후 JSON 저장 |
| 보안 질문 / 답변 | AES-256 암호화 후 JSON 저장 |
